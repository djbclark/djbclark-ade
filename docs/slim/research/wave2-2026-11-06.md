## 3. git filter-repo (a40bce5 installed; 2.47.0 newest on PyPI)

- `--paths-from-file` accepts `literal:`/`glob:`/`regex:` lines and `old==>new` rename lines. **Tested on a scratch repo**: a rename-only line (`skills/a/==>moved/a/`) does not select the path and the path is dropped. **E1 recipe rule**: every moved path needs a selecting line AND a rename line, e.g.

      skills/a/
      skills/a/==>skills/a/

  (one pass, history kept).
