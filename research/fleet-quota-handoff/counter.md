# Counter-evidence and limits

A1. Continuity already handles single-agent failover without cooperation from the failed provider. Reject the blanket premise that no useful Paseo feature exists (E0001, E0022).

A2. Its context is bounded, and subagents are excluded by default. Do not infer complete fleet-state/relationship adoption (E0003, E0004). Opened catalog and README agree on the successor model, not proof of fleet-atomic behavior.

A3. ACP resume is capability-specific and restores an existing session; it is not universal cross-vendor import (E0006, E0007). Terminal release can destroy the underlying command (E0008, E0009).

A4. State-saving APIs can default to empty custom state (E0021). Successful checkpoint architectures in LangGraph/AutoGen are analogies, not installed Paseo features.

A5. Retry alone does not solve exhausted billing/quota (E0016). Jitter addresses synchronized request traffic, not lost ownership or unrecorded side effects (E0014).

A6. tmux reattachment concerns programs already inside tmux; reptyr does not advertise macOS support (E0018, E0019). Neither establishes generic child-agent reparenting.

A7. No live migration/fault-injection, plugin code audit, or end-to-end adoption test was performed. No independent web-research reviewer was commissioned; the Gemini slice is a local code capability audit only. These gaps are disclosed rather than filled from recall.
