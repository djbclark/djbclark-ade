### Fixed

- `agent_footer_gate` no longer tells a sub-agent that cannot write files to write a report and a `.done` marker: the built-in types Explore, Plan and web-fetch, and any agent definition (`.claude/agents`, `~/.claude/agents`) whose `tools:` lists neither Write nor Bash, get the new `docs/dispatch-footer-readonly.md` (the final message is the report, under about 3,500 characters), the resume guard is skipped for them, and the hook's `additionalContext` tells the caller to save the final message and not to wait for a `.done` file. The type is resolved the way Claude Code resolves `subagent_type` (exact match, else the one type with the same name after lower-casing and dropping whitespace, dashes and `_`), so `explore`, `web_fetch` and `Web Fetch` count too; an ambiguous or unknown name keeps the standard footer. Types that can write keep the standard footer. (#900)
