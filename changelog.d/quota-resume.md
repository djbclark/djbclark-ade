### Added

- Added `bin/ade-net-resume --quota` (off by default): a second pass resumes our own Pi agents (z.ai `zai/` models) stopped by a provider quota window once a fresh `aiuse` sample shows the window reset. It recorded `quota-wait` in the shared ledger, failed closed on a stale, missing or unparseable `aiuse`, kept every network-path guard, skipped agents that session-guard held, resumed one agent per pool per scan, and accepted a `closed` agent only with an unchanged ledger entry. Added `--quota-per-pool`, `--quota-grace-seconds` and `--only-agent` (restricts both passes). Docs: `docs/net-resume.md`. The launchd template stays dry-run without `--quota`. (#613)
- Added an upstream bug draft for the Paseo daemon worker crash from an uncaught `kill EPERM` in a plugin timer (`docs/upstream-issues.md` item 20, not filed). (#613)
