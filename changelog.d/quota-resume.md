### Added

- Added `bin/ade-net-resume --quota` (off by default), a second pass that resumed our own Pi agents (z.ai `zai/` models) stopped by a provider quota window once a fresh `aiuse` sample showed the window reset. The pass recorded `quota-wait` in the shared ledger, failed closed on a stale, missing or unparseable `aiuse`, refused while any window over 360 minutes was exhausted, kept the ledger, cap, lock, ancestry and re-inspection guards of the network path (the endpoint probe is not used), skipped agents that session-guard held, resumed at most one agent per pool per scan and per 600 seconds, never re-read an agent's logs before the reset check once its error event was in the ledger, and accepted a `closed` agent only with an unchanged ledger entry. Added `--quota-per-pool`, `--quota-grace-seconds` and `--only-agent` (restricts both passes). Documented in `docs/net-resume.md`; the launchd template was left dry-run, without `--quota`. (#613)
- Added an upstream bug draft for the Paseo daemon worker crash from an uncaught `kill EPERM` in a plugin timer (`docs/upstream-issues.md` item 20, not filed). (#613)
