### Added

- `bin/ade-net-resume --quota` (off by default): a second pass resumes our own Pi agents (z.ai `zai/` models) stopped by a provider quota window once a fresh `aiuse` sample shows the window reset. It records `quota-wait` in the shared ledger, fails closed on a stale, missing or unparseable `aiuse`, keeps every network-path guard, skips agents that session-guard holds, resumes one agent per pool per scan, and accepts a `closed` agent only with an unchanged ledger entry. New `--quota-per-pool`, `--quota-grace-seconds` and `--only-agent` (restricts both passes). Docs: `docs/net-resume.md`. The launchd template stays dry-run without `--quota`. (#613)
