### Added
- Added `bin/review-launch`, the permanent review boundary: one `claude -p` with `--tools Read,Grep,Glob` (`--mode read-only` adds WebFetch and WebSearch), `--permission-mode default`, no setting sources, no MCP, no hooks and `blockReadsOutsideWorkingDirectories`; it refuses bypass flags and variables, proves the boundary from the run's init event, ends the run with exit 77 on any tool or path outside it, and refuses every launch until its cached per-version self-check (`review-launch --check`) has shown outside reads refused (slim-down E8) (#0).
- Added `bin/review-pr PR`, rule 11's local review: Claude through `review-launch --mode review` on the PR's exact head in a clean detached worktree; it prints the `adversary-verdict:v1` marker to paste, refuses an untrusted author unless `--allow-untrusted`, and never posts (slim-down E8) (#0).
- Added the `adversary-marker` Action (`.github/workflows/adversary-marker.yml`, `bin/adversary_marker.py`): on `workflow_run` of Tests and on `gh workflow run adversary-marker.yml -f pr=N` it judges the PR body's marker against the head and posts the `adversary-marker` commit status from the `ade-merge-gate` App, counting an APPROVE only in a body last edited by the repository owner or an OWNER, MEMBER or COLLABORATOR author (the operator approves an outside PR by editing its body); the marker parser moved unchanged from the PR waiter with its tests (slim-down E8) (#0).
