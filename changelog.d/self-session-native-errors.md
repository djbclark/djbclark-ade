### Fixed

- `ade-self-session` no longer hides why a native Paseo command failed: `native()` reads Paseo's `{"error": {"code", "message"}}` envelope from stderr (or stdout) and raises with the code, message, exit status and a bounded, secret-scrubbed stderr tail; "outcome unknown" is kept only for a timeout, an OS error or a nonzero exit with no JSON on either stream. The reason is stored as `native_error` in the transaction record (`creation-unknown`, `archive-unknown`, `send-unknown` are diagnosable from the file; a later success moves it to `resolved_native_error`). 2026-11-14: a self-handoff lost both `WORKSPACE_NOT_FOUND` and an empty-stdout rc 1 archive error. (#668)
- `handoff` checks `paseo workspace ls --json` before saving the intent; when the predecessor's workspace is gone the successor is launched with `--new-workspace local` (recorded as `workspace_placement`), not `--workspace`. `finish` raises a specific error when the archive error names an agent that is not the predecessor ("Paseo resolved archive to a different agent ..."), never retrying or forcing. `docs/self-session.md` C0 documents both manual fallbacks. (#668)
