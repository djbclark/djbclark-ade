### Added

- `bin/agent-id <AGENT_ID> [--json]`: prints the agent id, workspace name, and the window/tab and tab/pane placement fields for the harness the agent runs in, so any agent mentioning another to a human can name it fully (docs/agent-identity.md, operator rule 2026-11-20). Fields that do not apply or resolve print `?`. The workspace is read from `workspaceId` in the Paseo state file, the Paseo tab from `paseo agent inspect`'s `Name`; the id is validated (UUID or hex prefix, never a flag), every subprocess call has a timeout, and a missing binary or odd herdr JSON gives `?`, not a traceback. `bin/agent-id` also resolves a local Claude Code session UUID (or unique prefix, dead pids skipped) from `~/.claude/sessions/<pid>.json` to the `ListAgents`/`SendMessage` name (docs/agent-identity.md, docs/orchestration-practices.md 5a item 6).
