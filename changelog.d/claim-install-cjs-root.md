Received undefined`, `paseo plugin install` rc 1, status `failed`; #638 D2). New `resolvePluginRoot` (returns root + source): a real `file:` URL still wins (plain Node ESM, the tests); otherwise Paseo's own install record (`~/.paseo/config.json` `plugins["ade-claim"].path`), otherwise the shared checkout `~/src/djbclark-ade/plugins/ade-claim`, using the account's home directory (`userInfo()`), never `$HOME`; the root and its source are logged once at load. The trusted `bin/ade_claims.py`, `bin/ade-git-guard` and `libexec/agent-bin` are found from it by the parent walk (env `ADE_CLAIMS_PY` / `ADE_GIT_GUARD` / `ADE_AGENT_BIN` override). Tests cover each source and load `hook.mjs` with `import.meta` replaced by `{}` as Paseo's bundle does. (#644)
