- Bash habits gate: the whole check now runs under a 20 s time budget (`BASH_HABITS_GATE_BUDGET` overrides it) and a command that exceeds it is denied (fail closed) with "split or simplify", instead of the hook hitting the 60 s timeout and letting the command run unchecked; about 2 ms per call (#918)
