### Added
- `bin/review-launch` keeps a killed paid review recoverable: `--checkpoint` (a best-effort prompt protocol, on by default for fable, opus and astra models with `--evidence-dir`), a zero-AI `checkpoints.md` written from `stream.jsonl` on every non-zero end (exit 77, 124, a signal) and by `review-launch checkpoints DIR`, and `--resume-from-evidence DIR` (a new, tainted run whose prompt is the dead run's prompt plus its notes). (#PR)
- `bin/review-launch --detach` starts the review in a session of its own and returns the run dir and pid at once; the run ends with `RUN/result.json` and `RUN/done`, and survives the end of the caller's job or session. (#PR)
- `bin/review-launch` pause-ask (queue 103 part 1): `--pause-on-timeout` and `review-launch pause DIR` stop the claude child (SIGSTOP), ping `hermes-ping` and wait for `review-launch resume|abort DIR`; an unanswered pause aborts after `--pause-max` and a resumed run is tainted in its `--json` record. A real out-of-scope read stays fatal (exit 77) and never pauses. (#PR)
