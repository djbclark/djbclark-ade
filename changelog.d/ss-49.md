### Added

- `ade-self-session handoff` ends `creation-refused` (terminal, CLI exit 3) when Paseo refuses `agent run` with a code it raises before creating anything (`INVALID_THINKING_OPTION`, `INVALID_OPTIONS` and the like), returns no agent id and `agent ls --label ade.handoff=TOKEN` lists none, instead of `creation-unknown`: no reconcile is needed, the predecessor keeps working, the send guard and the succession ledger treat it as dead, and a new `handoff` replaces it (the earlier reason kept as `refused_before`). A retry first re-probes the old token and is refused if an agent carries it. A timeout, a missing code, any other code (`AGENT_CREATE_FAILED`, `DAEMON_*`, `UNKNOWN_ERROR`: Paseo raises them after creating the agent too), a labelled agent or unparsable output stays `creation-unknown` (#748).
