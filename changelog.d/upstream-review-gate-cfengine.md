### Added

- `claude/hooks/upstream_review_gate.py` (2026-11-12) is a Claude Code `PreToolUse` hook that denies writes CFEngine upstream would see, and only those: `gh` writes and `git push` whose target is a GitHub repository of `cfengine` or `NorthernTechHQ` (explicit `-R`/URL/`gh api` endpoint first, then the directory's remotes), mutating requests to `*.atlassian.net`, and Composio Jira writes. It replaces the unregistered shell hook `~/.claude/hooks/upstream_review_gate.sh` and closes its two gaps (a `gh api` path was never read; `gh api -f/-F/--field/--raw-field/--input` without `-X` is a POST and was not seen); reads and other third-party repositories pass. Contract and limits in `docs/upstream-review-gate.md`; registering it in `~/.claude/settings.json` is a separate step (#563).
