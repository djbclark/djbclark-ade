### Added

- `bin/ade-supervisor-scan`: each scan now writes the re-handoff it would perform for a stuck Pi agent (who, which exhausted account, which healthy alternative) and logs it. The default is a dry run that archives and relaunches nothing. `ADE_SUPERVISOR_REHANDOFF=live` calls `bin/ade-supervisor-rehandoff`, which re-hands each planned agent through `ade-self-session handoff --predecessor` and leaves an agent with no healthy alternative where it is. The handoff creates a successor but does not archive the predecessor; that waits for a verified first turn. Proven against a fake handoff, so the test never reaches a live Paseo (Carried 70, Carried 103).
