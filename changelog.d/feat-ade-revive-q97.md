### Added

- `bin/ade-revive`: added a supported, audited revive command (`ade-revive ID [--reason TEXT] [--message TEXT] [--allow-any] [--dry-run] [--json] [--timeout S] [--paseo PATH]`) that validates UUIDs, refuses replaced/handed-off agents, archived successors, enrolled-role replacements, and cyclic ledgers even with overrides, exits `0` idempotently when already live, authorizes owner-proven (`PASEO_AGENT_ID`) or operator-approved (`ADE_ALLOW_ARCHIVED_SEND=<id>` / `--allow-any`) revives, logs `event: "revive"` via `ade_send_guard.log_revive`, un-archives without a prompt via `paseo agent reload --json -- ID`, proves `Archived: false` by polling `paseo agent inspect`, and optionally delivers `--message` afterward while keeping `bin/ade_send_guard.py`'s careless-send refusals intact (#973)
