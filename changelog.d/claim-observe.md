### Changed

- `ade-claim` Paseo plugin: a true observe-only mode for **every** hook (#638 D1). Before, `ADE_CLAIM_DRY_RUN` gated only the W2 create; the archive release, owner bind and `agent.open.before` (`ADE_CLAIM_ID` export, `libexec/agent-bin` `PATH` prepend) still acted. Now one predicate (`resolveClaimMode`) is re-read on each hook call (no daemon restart): env `ADE_CLAIM_DRY_RUN` forces observe, else `~/.local/state/djbclark-ade/ade-claim.mode` must say `enforce` (own-user plain file, no symlink, not group/world-writable, 64-byte cap); a missing or odd file means observe, so a fresh install observes. In observe every hook logs its planned argv or env delta and does nothing else (and never throws), and each call appends a line to `~/.local/state/djbclark-ade/ade-claim-observe.jsonl` (0600, rotates at 1 MiB) for the soak. (#641)
