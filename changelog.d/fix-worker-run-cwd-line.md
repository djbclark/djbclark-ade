### Fixed

- `ade-worker-run`: when a worker is placed in a directory other than the one the brief is about (a launch into a box whose cwd is the repo's primary checkout, or a minted box), the brief the worker receives now carries one line before the footer pointer: with `--cwd`, `Your session starts in <primary checkout>; run every command from <--cwd> (cd there or git -C); never edit or commit in <primary checkout>.`; with no `--cwd` (the lead stands in its own claimed worktree) a line that names no work directory, `Your session starts in <primary checkout>, the shared primary checkout: never edit or commit there; work only in the worktree your brief names.` Paths are shell-quoted; a directory name with a control character is refused; under `--no-footer` a last argument that is no brief (a flag value) is never rewritten and the moved launch is refused. Before, only the launcher's stderr said so. A launch that is not moved (a case-variant spelling of `--cwd` included) gets no line. (#893)
