### Added

- `libexec/agent-bin/gh` + `bin/ade-gh-guard` (mg-52, queue Carried 57; operator ruling 2026-11-16, B2 + B5): a `gh` PATH shim that judges a `gh` write (`pr`/`issue` create, new, edit, comment, review, close, reopen; `api` with a body flag) for a live adversary APPROVE marker in the `gh` process itself, from its real argv, cwd, operand files and stdin, with the hook's own `judge` (one module, no copy). A refusal is exit 4 and nothing runs; everything else is `os.execv` of the real `gh` with the same argv, stdin, exit status and environment. It skips every copy of itself, counts re-entries only when the real `gh` is a script, and fails closed only for a write it cannot read. `docs/adversary-gh-shim.md` has the install and what it never catches; `docs/code-review.md` rule 14 now promises only that the gate stops an agent's careless marker text, not deliberate obfuscation (`docs/threat-model.md` section 5 item 9 says the same).
